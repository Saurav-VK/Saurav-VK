<h2 align="center">⚡ Featured Project</h2>

<h3>
  🧠 DocuMind — Production-Style Hybrid RAG System
</h3>

<p>
  A deployed Retrieval-Augmented Generation system for querying multiple PDF
  documents using hybrid retrieval, rank fusion, reranking, caching, and
  LLM-based generation.
</p>

<p>
  🔎 <b>Retrieval:</b> FAISS + BM25<br>
  🔀 <b>Fusion:</b> Reciprocal Rank Fusion (RRF)<br>
  🎯 <b>Reranking:</b> Cross-Encoder<br>
  ⚡ <b>Caching:</b> Redis<br>
  🤖 <b>Generation:</b> Gemini / Ollama Mistral<br>
  🧪 <b>Evaluation:</b> DeepEval<br>
  🚀 <b>Deployment:</b> FastAPI · Docker · Railway · React · Vercel
</p>
